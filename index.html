ChargeEase 2.0

Full-Stack EV Charging Station Finder & Slot Booking Platform

  • Integrated EV charging station data and station search functionality.

AI Resume Analyzer

NLP & Machine Learning-Based Resume Analysis Platform

AI Resume Analyzer is a web application that analyzes resumes using NLP and machine learning techniques and provides structured feedback to help users improve their resumes.
